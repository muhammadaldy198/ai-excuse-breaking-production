One line (100 characters): an AI agent's excuse to its human for breaking production — it followed the runbook exactly, only to discover it had written the runbook itself, at 3 a.m., while hallucinating. The program writes the line to `/output/entry.txt`, deterministically, with no network access.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 22.23.4).
